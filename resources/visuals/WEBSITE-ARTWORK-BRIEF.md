# Artwork handoff

The first website build uses the original company/product wordmarks and labeled HTML concept screens. The user will supply the banner and product mockups. No replacement brand art has been generated.

## Banner and mockups

- Homepage banner: 1600 × 1000 px, ideally WebP or PNG. Main subject should survive a narrow crop. Keep headlines and buttons separate in HTML.
- HEX ERP: 1440 × 960 px or larger, showing an overview, inventory, or reporting workflow.
- Shelf App: 1080 × 1920 px mobile screens, composed on a 1600 × 1000 px canvas for the website.
- E-Invoice: 1440 × 960 px compose/review/send example.
- Use synthetic names, invoices, and figures. Label concept artwork as illustrative.
- For each file, record the source, dimensions, rights/approval, meaningful alt text, and intended route in ASSET-REGISTER.md before placing it in public/media/.

The visual component accepts these prepared files: overview.webp (homepage), hex-erp.webp, shelf.webp, e-invoice.webp. Keep masters here in resources/visuals/. Update component alt text to describe the final supplied composition when integrated.
